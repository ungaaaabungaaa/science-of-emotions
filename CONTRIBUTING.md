# Contributing

Keep changes small enough to verify. Describe observed behavior, expected behavior, and a reproducible example in an issue. Do not include private text or raw Reddit comments.

Run Python tests, JavaScript tests, and the static build as shown in the README. For parsing/counting changes, rerun the pinned full-data workflow and explain every report difference. Add tests for real changed behavior; keep fixtures original and small.

For UI changes, check keyboard selection, the same-label case, every split, and 320px/390px layouts. Preserve denominators and methods/source links. New tracking, personal text collection, diagnosis, or hosted models require separate design review.

AI tools can assist development; contributors remain responsible for understanding and verifying changes. Do not describe assisted work as solely handwritten. Keep claims tied to actual runs and distinguish this project's work from upstream results.

New code uses MIT; data retains Apache 2.0 attribution. Earlier history must remain recoverable.
